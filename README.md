<h1 align="center">STORM IMAGES</h1>

## **О проекте**
STORM IMAGES — программный комплекс для генерации и интеллектуального редактирования изображений на базе нейросети Qwen-Image-Edit с интеграцией специализированного LoRA-адаптера Scottzilla NSFW LoRA. Приложение предоставляет интерфейс в стиле Windows 11 Fluent Design с поддержкой тем оформления (STORM MIDNIGHT, STORM NIGHT, STORM DAY), динамическим холстом сравнения изменений, выбором директории для автосохранения и автоматической публикацией сгенерированного контента в каналы и группы Telegram.

## **Происхождение и базовые модели**
- **Нейросетевое ядро**: Модель редактирования изображений на базе **Qwen-Image-Edit** (`Qwen/Qwen-Image-Edit-2511`) от команды **Qwen (Alibaba Cloud)**.
- **LoRA-адаптер**: Специализированные веса **Scottzilla NSFW LoRA** (`ScottzillaSystems/qwen-image-edit-plus-nsfw-lora`).
- **Серверная часть**: Асинхронный микросервис на базе **FastAPI**, **Hugging Face Diffusers**, **PyTorch** и **Telegram Bot API**.
- **Десктопный клиент**: Архитектура **WPF / WinUI Fluent UI** (.NET 8.0) с использованием **CommunityToolkit.Mvvm**.

## **Технологический стек**
- **Языки программирования**: C# (.NET 8.0 / .NET 9.0), Python 3.10+, PowerShell
- **Пользовательский интерфейс**: XAML, Windows 11 Acrylic & Mica, мультитематическая система (STORM MIDNIGHT, STORM NIGHT, STORM DAY)
- **Нейросетевой стек**: PyTorch (CUDA), Hugging Face Diffusers, SafeTensors, Transformers, Accelerate, Pillow
- **Сетевой стек**: FastAPI, Uvicorn, HTTPX, Telegram Bot API
- **Пакетная сборка и защита**: Single-File Executable, цифровая подпись Authenticode SHA-256 (STORM TEAM)

## **Ключевые возможности**
- **Интеллектуальное редактирование изображений**: Загрузка исходного изображения через Drag & Drop, задание позитивного и негативного промптов, точная калибровка силы LoRA (0.0–1.5), числа шагов инференса (10–60) и соответствия промпту (CFG Guidance Scale).
- **Интеграция с Telegram-каналами и группами**: Прямая отправка созданных изображений в публичные и приватные каналы Telegram с настраиваемыми шаблонами описаний (промпт, сид, параметры LoRA).
- **Выбор папки сохранения**: Мгновенная настройка директории для автоматического сохранения всех изображений и сопутствующих файлов метаданных в формате JSON.
- **Галерея и история**: Встроенный каталог ранее созданных генераций с быстрым предпросмотром, копированием в буфер обмена, удалением и повторной отправкой в Telegram.
- **Мультитематический интерфейс**: Мгновенное переключение между 8 темами экосистемы STORM SOFT (STORM MIDNIGHT по умолчанию, STORM DARK, STORM NIGHT, STORM DAY, STORM MATRIX, STORM CYBERPUNK, STORM FANTASY, STORM WARHAMMER 40K).
- **Управление сервером инференса**: Автоматический запуск и мониторинг состояния локального сервера, проверка доступности CUDA и объема видеопамяти (VRAM).

## **Поддерживаемые платформы**
- **Операционные системы**: Windows 10 (20H2–22H2), Windows 11 (21H2–24H2) x64
- **Аппаратные требования**: Видеокарта NVIDIA с поддержкой CUDA (рекомендуется от 8 ГБ VRAM) или режим CPU для ознакомления.

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_IMAGES_0.0.3_Setup.exe` или портативный архив `STORM_IMAGES_0.0.3.zip` из секции **Releases** на GitHub.
2. Запустите инсталлятор и следуйте инструкциям на экране.
3. В настройках укажите желаемую папку для сохранения изображений и при необходимости введите токен Telegram-бота и ID канала.
4. Запустите локальный AI-сервер с помощью встроенной кнопки в боковом меню или файла `run_server.bat` в папке `StormImagesServer`.
5. Загрузите изображение, введите промпт и нажмите кнопку **Сгенерировать изображение**.
